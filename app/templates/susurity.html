Безопасность

Мы знаем, как важна защита ваших данных. Поэтому мы используем собственную реализацию криптоалгоритмов, ведь так надежнее!



🔐 Криптография

Мы используем токены JWT с подписью RSA — де-факто многолетним стандартом электронной подписи. Для каждого пользователя мы генерируем уникальную пару ключей, на которой строятся его токены.


💻 Надежные компоненты

В основе любой криптосистемы лежит надежный ГПСЧ. Силами внутренней разработки мы реализовали самый стойкий генератор, но ребята из ДКБ почему-то ругаются на "низкую энтропию" и забрасывают нас замечаниями. Мы долго это обсуждали и даже пробовали гуглить, но так и не поняли, что они имеют в виду.


🔍 Прозрачность

Мы ценим честность и открытость превыше всего, и поэтому мы открыли исходный код бэкенда. В нашей криптографии все прозрачно — убедитесь в этом сами!

Наша реализация генератора from gmpy2 import next_prime from random import SystemRandom size = 2048 rounds = 16 rand = SystemRandom() exp = rand.sample(range(32, size//2 - 1), rounds) def generate_rsa_key_pair(): def generate_int(): g = 2 ** (size//2 - 1) for i in range(rounds): g += 2**exp[i] * rand.randint(0, 1) return g def generate_prime(): return int(next_prime(generate_int())) p = generate_prime() q = generate_prime() while p == q: q = generate_prime() n = p*q phi = (p-1)*(q-1) e = 65537 d = pow(e, -1, phi) return (n, e), (p, q, d)
